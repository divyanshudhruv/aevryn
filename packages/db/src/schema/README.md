Single-user, 15-table schema for Aevryn.

Source of truth: `src/schema/` (Drizzle). Migrations in `src/migrations/`
are generated by drizzle-kit; `supabase/migrations/20260911130000_supabase_glue.sql`
holds the raw-SQL parts Drizzle cannot express (triggers, RPCs, Realtime, Storage).

Prefixes: `wp_` workspaces, `grp_` groups,
`prf_` user_profiles, `thd_` threads, `wf_` workflows,
`pls_` plan_steps, `msg_` chat_messages, `run_` runs, `act_` run_activities,
`apv_` approval_requests,
`not_` notifications, `key_` workspace_api_keys, `fil_` files,
`gs_` global_settings, `ts_` thread_settings, `cal_` callouts,
`bnd_` thread_workflow_bindings.
